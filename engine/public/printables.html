NFC tag map

Using the free NFC Tools app, write each URL below to that prop's sticker (Write → Add a record → URL/URI). Test-tap each after writing.

If a tag ever fails, guests can still use “I found something” in the app and pick the exhibit number — the meaning is tied to the item, not the tag.
