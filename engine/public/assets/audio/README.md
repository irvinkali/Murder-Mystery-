# Ambient audio (optional)

The Gallery Screen looks for one looping track per phase here. Drop in MP3 files
named exactly:

- `arrivals.mp3`     (Phase 1)
- `unveiling.mp3`    (Phase 2)
- `investigation.mp3`(Phase 3)
- `keystone.mp3`     (Phase 4)
- `accusation.mp3`   (Phase 5)
- `reveal.mp3`       (Phase 6)

They're entirely optional — if a file is missing, that phase simply plays no
sound. On the gallery screen, tap **“Enable ambient sound”** once (browsers
require a tap before audio can start), and the right track loops as phases
change.

Keep files small (a minute or two, looped) and royalty-free.
